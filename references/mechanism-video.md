# 机制可视化视频

Remotion 输出现在用逐帧变化的图形说明 Spec Lab 的六个阶段，而不只播放文字。
沿用[解释导出](explanation-surfaces.md)中的 `--format remotion --lang zh-CN`
或 `--lang en`，不新增安装依赖、运行时下载、旁白 API 或 Manim 后端。

视频使用捕获快照中的路径、候选、直接选择、依赖和 capsule。文件卡片进入候选集合，
选中的要求从其所属规范移出，依赖按层展开，共享依赖只画一个节点。上下文装配图
随后把要求移到 capsule 一侧，显示真实字节数、预算和摘要。最后的关闭边界表明
`authority: none` 和 `receipt_created: false`，不会播放批准或执行成功的动画。

## 不能由动画推断的事实

路径到候选的连线表示捕获的**集合结果**，不声称知道每个路径匹配哪一份规范，
不重新实现 glob 匹配。选择动画只使用 `resolved[].spec_id` 的归属关系；候选不等于
语义适用，也不等于正式激活。这里没有重新执行 Router，没有新增激活记录。

依赖箭头保留原方向：`from` 依赖 `to`。分层和动画节奏是阅读安排，不是实测因果、
执行先后或性能数据。跨层边从节点外侧绕行，避免把中间节点误画成依赖端点。
已有 v1 IR 的六个分镜和 1080 帧保持不变；36 秒仍只表示阅读时间。

装配图是示意。预算条始终使用捕获的完整 UTF-8 字节数，不累加虚构的部分字节，
也不把动画完成比例说成校验进度。视频不展示完整原文，画面给出配套
`explanation.json` 中 `/source/snapshot/capsule/text` 的位置。规范原文和摘要不变。

空选择、整份规范选择和混合选择分别处理，不把没有 Requirement 图说成没有规范。
超过图形阅读预算时显示总量和明确的来源提示，不截断 IR 或绘制一个冒充完整图的
子图。长路径、长名称的集合使用相同的总量回退，完整值仍在快照中。

## 验证

`tests/explanation_frames.test.mjs` 检查来源一致性、共享依赖、拓扑分层、空／整份／
混合选择、坏图拒绝、预算和逐帧确定性。既有 HTML、p5 与导出校验保持原入口。

`tests/runtime/run.mjs` 在实际 Remotion 渲染中比较每个阶段早期与稳定时刻的图形
区域像素。比较排除标题、字幕和进度条，文字换页无法冒充机制动画。它还反向定位
并检查重复帧，生成完整中英文 MP4，再验证编码、帧数、时长和精确来源保持情况。

这些测试验证实际图形变化、来源和可复现性，不证明学习效果、任意图形都易读、
规范本身正确或整站可访问性。不要将它称为 3Blue1Brown 官方作品或完整风格复刻。
这是 RF 自己的机制演示，没有使用第三方视频素材、标志或配音。

此变更不调整 p5 手机端的小字问题，不修改实时 Spec Lab 页面，也不发布 RF 或
Spec 版本。更新未合并分支时，按 PR 中的依赖顺序评审，不能绕过现有 CI。
