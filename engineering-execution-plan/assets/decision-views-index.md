# Decision Views

This file is the rebuildable entrypoint for non-normative ADR working views.
Atomic ADR documents and `DECISIONS.md` remain the architecture authority.

Use `epctl set-decision-view` to preview or apply view membership and
`epctl reindex` to rebuild generated projections.
